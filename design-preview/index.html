TONYAgent — the window, at five widths

Captures of the built window (app/dist) in Chromium, driven over CDP by scripts/capture_window.py. These are the baseline for phases 4–7 of the workspace refine: what the transcript, the run panel and the docks looked like before the spine, the tool rows and the Code-mode unification. Nothing here is a mock — it is the same bundle the packaged window serves.

No core is attached: scripts/preview_host.js answers the boot requests and replays one turn, which is what puts a transcript, a plan and a token count on screen. The captures are committed — a baseline that lives only on the machine that took it is not a baseline, which is exactly how the previous pass lost its “before”.
